# 🚀 Dev Session Tracker PRO

A modern, responsive developer productivity tracker built with **HTML, CSS, and Vanilla JavaScript**.

Track coding sessions, monitor productivity, manage your session history, and analyze your programming progress through a modern dashboard.

## ✨ Features

- ⏱️ Live timer with Start, Pause, Resume, and Reset
- 🎯 Focus, Learning, and Deep Work modes
- 📋 Session history with Edit and Delete
- 🔍 Search and date-based filtering
- 📊 Productivity statistics and coding streaks
- 💾 Local Storage persistence
- 📥 JSON import and export
- 🔄 Automatic session backup and recovery
- ⚠️ Leave Page Warning
- ⚙️ Settings modal
- 📱 Fully responsive design
- 🎨 Modern dark UI with glassmorphism

## 🛠️ Tech Stack

- **HTML5** – Semantic structure
- **CSS3** – Responsive design, gradients, and glassmorphism
- **JavaScript (ES6+)** – Application logic and DOM manipulation
- **Local Storage API** – Persistent session data
- **Lucide Icons** – Interface icons

## 🚀 Getting Started

1. Clone the repository:

   `git clone https://github.com/samojahn200215/dev-session-tracker-pro.git`

2. Open the project folder.
3. Launch `index.html` in your browser or use a local development server.

No build tools or JavaScript frameworks are required.

## 💾 Data Storage

All session data is stored locally in your browser using the **Local Storage API**.

Sessions are not synchronized between devices. Use the built-in JSON export and import functionality to back up or transfer your data.
